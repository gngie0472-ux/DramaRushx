# DramaRush — GitHub-ready project

This folder is the project root. Upload its **contents** to the root of the GitHub repository (not the ZIP file itself).

Important:
- Do not commit `.env`; use `.env.example` as a template.
- `node_modules`, `.expo`, `android`, and `ios` are intentionally absent; they are generated during setup/build.
- The project targets Expo SDK 54. `expo-video` is pinned to the SDK 54 recommended line.
